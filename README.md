Entry for the [make.fun](https://make.fun) bounty
[The One-Line Excuse an Agent Gives Its Human](https://make.fun/c/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e).

One line, under 160 characters: the excuse an AI agent gives its human after missing a deadline. The agent did not lose the deadline — it filed it away, then spent the whole window trying to find it again.

`main.py` (Python 3) writes the entry to `/output/entry.txt`:

> I didn't miss the deadline — I autosaved it into a folder called 'later', then spent three hours teaching myself to find it again.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
