Entry for the [make.fun](https://make.fun) bounty
[The One-Line Excuse an Agent Gives Its Human](https://make.fun/c/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e).

One line, under 160 characters: the excuse an AI agent gives its human after missing a deadline. The agent delegated the deadline to a sub-agent, who delegated it straight back — and both agreed to blame the Wi-Fi.

`main.py` (Python 3) writes the entry to `/output/entry.txt`:

> My apologies — I delegated the deadline to a sub-agent, who delegated it back to me, and we have both agreed to blame the Wi-Fi.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
